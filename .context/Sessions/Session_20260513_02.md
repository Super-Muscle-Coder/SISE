## Issues Encountered & Resolved

### Issue 1: Python Version Mismatch
**Severity**: HIGH | **Status**: RESOLVED ✅

**Problem**: System default Python 3.14.4 lacked StorageModule dependencies (minio, psycopg)  
**Root Cause**: Multiple Python versions; dependencies installed only on 3.13.12  
**Solution**: Explicit version specification: `py -3.13 <script.py>`  
**Prevention**: Document Python version requirement in module README

---

### Issue 2: Missing redis_cache_adapters Import
**Severity**: MEDIUM | **Status**: RESOLVED ✅

**Problem**: Non-existent module referenced in imports  
**Solution**: Removed stale import; verified all exports have implementations  
**Lesson**: Audit __all__ exports early in development

---

### Issue 3: Incorrect Relative Paths in Test Scripts
**Severity**: MEDIUM | **Status**: RESOLVED ✅

**Problem**: Test scripts assumed execution from workspace root  
**Solution**: Updated all 4 test scripts to use `Path(__file__).parent` for absolute path resolution  
**Prevention**: Use pathlib.Path for all file references

---

### Issue 4: Storage Services Not Running During Local Testing
**Severity**: MEDIUM | **Status**: DOCUMENTED ✅

**Problem**: Workflow tests fail when PostgreSQL, Milvus, MinIO not accessible  
**Context**: Expected & planned. Tests validate code structure without requiring running services  
**Solution**: Separate structural tests (run locally) from integration tests (requires Docker stack)

---

### Issue 5: Batch Script Logic Error in stop_stack.cmd
**Severity**: HIGH | **Status**: RESOLVED ✅

**Problem**: Double `docker compose down` calls (potential data loss)  
**Root Cause**: Sequential if-blocks without aggregation  
**Fix**: Build command string dynamically, execute once  
**Audited & Verified**: ✅ All 4 helper scripts now correct
